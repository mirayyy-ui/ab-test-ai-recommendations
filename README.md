## A/B-тест AI-модели рекомендаций на маркетплейсе
> задание, представленное на первом этапе хакатона School of Analytics

Анализ 30-дневного продуктового эксперимента по внедрению новой AI-модели
рекомендаций на главной странице мобильного приложения маркетплейса.

### Контекст задачи

Продуктовая команда провела A/B-тест новой AI-модели рекомендаций,
которая анализирует историю покупок, поисковые запросы, поведение в
предыдущих сессиях и предпочтения похожих пользователей для формирования
персонализированной ленты.

Пользователи были разделены на две группы:
- **Control** - старая рекомендательная система
- **Test** - новая AI-модель

Период: 01.07.2026 – 30.07.2026 


**Цель исследования** - определить, улучшает ли новая рекомендательная система ключевые продуктовые и бизнес-метрики, а также понять, можно ли масштабировать модель на всю аудиторию.

Необходимо подготовить независимую оценку результатов эксперимента и
сформировать рекомендации для руководства относительно
дальнейшего масштабирования модели.

### 3. Анализ пользовательской воронки

#### Общая воронка (по пользователям)

| Этап | Control | Test |
|---|---|---|
| Users with impressions | 24 596 | 24 973 |
| Users with clicks | 17 576 | 19 354 |
| Users with orders | 2 900 | 3 771 |
| Users with returns | 172 | 287 |

#### Конверсии по этапам

| Этап | Control | Test | Δ, п.п. |
|---|---|---|---|
| Impressions → Clicks | 71.46% | 77.50% | +6.04 |
| Clicks → Orders | 16.50% | 19.48% | +2.98 |
| Orders → Returns | 5.93% | 7.58% | +1.65 |
| Repeat purchase rate | 7.03% | 10.95% | +3.92 |

#### Узкие места

1. **Clicks → Orders - главное узкое место воронки.**
   Даже в Test более 80% пользователей, совершивших клик, не оформляют заказ.
   Это означает, что основной потенциал роста лежит не в рекомендательной модели,
   а в оптимизации пути к покупке (карточка, корзина, оформление, цена).

2. **Рост return rate** - часть дополнительного трафика оказывается менее качественной.
   Требуется анализ причин возвратов.

3. **Этап Impressions → Clicks - самый успешный** для новой модели (+6.04 п.п.).
   AI-рекомендации действительно делают контент более релевантным.

### 4. Анализ результатов A/B-теста

#### Выбор статистических методов

- **Z-тест для двух пропорций** - для метрик-долей (CTR, конверсии, return rate),
  т.к. n > 20 000 в каждой группе, распределение выборочных пропорций близко к нормальному.
- **Mann–Whitney U** - для непрерывных скошенных метрик (GMV, margin, AOV).
  Проверка нормальности через Shapiro-Wilk дала p < 1e-80, skewness 5–7 → t-тест неприменим.
- **Поправка Benjamini–Hochberg** - при множественных сравнениях в сегментационном анализе.
- **OLS с interaction-членами** - для проверки гетерогенности эффекта.

#### Ключевые метрики

| Метрика | Control | Test | Δ абс. | Δ, % | p-value | 
|---|---|---|---|---|---|
| **GMV / user** | 211.15 ₽ | 286.41 ₽ | +75.27 ₽ | **+35.65%** | < 0.001 | 
| **Gross margin / user** | 35.11 ₽ | 46.32 ₽ | +11.21 ₽ | **+31.92%** | < 0.001 | 
| **CTR** | 7.30% | 9.02% | +1.72 п.п. | +23.55% | < 1e-200 | 
| **Click-to-Order Conversion** | 8.40% | 9.13% | +0.73 п.п. | +8.67% | 0.0002 | 
| **Premium Conversion** | 1.67% | 2.11% | +0.44 п.п. | +26.35% | 0.0003 | 
| **Average Order Value (AOV)** | 1 662.77 ₽ | 1 696.19 ₽ | +33.43 ₽ | +2.01% | 0.110 |
| **Return Rate** | 5.54% | 6.82% | +1.29 п.п. | +23.28% | 0.025 | 
| **Customer Support Rate** | 0.48% | 0.76% | +0.28 п.п. | +57.88% | 0.0001 | 

#### Интерпретация

**Позитивные сигналы:**
- Рост GMV и gross margin сопоставимы (+35.65% vs +31.92%) - эффект не размывается низкомаржинальными продажами
- AOV не изменился → рост идёт за счёт **числа покупателей**, а не размера чека
- CTR и Click-to-Order выросли - AI-рекомендации лучше релевантны
- Premium Conversion +26% - долгосрочный сигнал ценности

**Негативные сигналы:**
- Return Rate +23.28% - часть дополнительного спроса менее качественная
- Customer Support Rate +57.88% - рост нагрузки на поддержку

### Выводы

1. **Модель коммерчески перспективна.** GMV/user +35.65%, Gross margin/user +31.92%
   при незначимом изменении AOV - рост идёт за счёт расширения базы покупателей.

2. **Полный rollout преждевременен.** Рост возвратов (+23%) и обращений
   в поддержку (+58%) требует оценки чистого экономического эффекта.

3. **Эффект неоднороден.** Сильнее всего на Android, слабее на iOS,
   практически отсутствует на Web. Различия по регионам/возрасту/трафику - на грани значимости.

4. **Главное узкое место** - переход «клик → заказ»: > 80% кликнувших
   не доходят до покупки даже в Test-группе.

---

### Рекомендации Product Leadership

1. **Поэтапное масштабирование**, а не 100% rollout:
   - Android - полный эффект, можно масштабировать
   -  iOS - доработать модель (эффект на 56 ₽ слабее)
   -  Web - пересмотреть подход (эффект почти нулевой, +5%)

2. **Мониторинг guardrail-метрик** в проде:
   - Return rate
   - Customer support rate
   - Gross margin / user (основная бизнес-метрика)

3. **Дополнительные данные для расчёта чистой прибыли:**
   - Стоимость обратной логистики и обработки возвратов
   - Стоимость одного обращения в поддержку
   - Retention и cumulative GMV за 60–90 дней

4. **Оптимизация воронки «клик → заказ»** - потенциал роста выше,
   чем у самой рекомендательной модели.
